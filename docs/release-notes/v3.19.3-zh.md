# CC Switch v3.19.3（二次开发版）

> 本版是 `Jyy1529/ccs-two-update` 的 Windows 二次开发手动发布，重点完成 Provider 功能生效范围控制，以及 DeepSeek / Pi 的 MCP 与 Skills 状态持久化。

**[English →](v3.19.3-en.md) | [日本語版 →](v3.19.3-ja.md)**

## 主要更新

- 新增 Provider 功能生效范围设置：本地代理自动重试、Codex 前端/后端子代理角色路由、Codex 审批模型路由均可独立开关并限制应用范围。
- DeepSeek / Pi 的 MCP 与 Skills 启用状态写入数据库 schema v17；MCP 条目同步到各自目录下的独立 `mcp.json`，Skills 启用状态独立保存在数据库中。
- 设置页补齐 DeepSeek / Pi 配置目录选择、恢复默认和四语言文案；MCP 表单与 Skills 导入入口可正确识别二者。
- DeepSeek / Pi Provider 表单使用扁平 `baseUrl` / `apiKey` / `model` JSON，不再误用 Claude 的 `env/config` 或 Universal Provider 入口。
- Codex 角色路由监听地址改为严格回环 IP 校验，拒绝 wildcard、远端地址和格式伪造值。

## 验证摘要

- `cargo fmt --check`、`cargo clippy --all-targets --all-features -- -D warnings`：通过。

## Windows 发布说明

- 本版提供面向 Windows `x86_64` 的 MSI 和 NSIS 安装程序，仅支持手动下载安装。
- 安装器未进行 Authenticode 代码签名，Windows SmartScreen 可能显示未识别发布者。
- 本版未生成 Tauri updater artifact、`.sig` 或 `latest.json`，应用内自动更新暂不可用；不会从上游更新通道拉取安装包。
- 下载后请核对 GitHub Release 中列出的 SHA-256。当前主机未执行真实安装/升级，以避免覆盖已有 CC Switch 安装；应在 Windows Sandbox 或虚拟机中验证安装流程。
