# CC Switch v3.19.4 (Fork Release)

> Windows manual-install release of `Jyy1529/ccs-two-update`. This patch corrects the DeepSeek Harness and Pi Coding Agent integrations against their published CLI contracts and fixes the Pi identity, icon, environment checks, and configuration projection.

**[中文版](v3.19.4-zh.md) | [日本語](v3.19.4-ja.md)**

## Highlights

- Settings now detects the official `dsh` / `@deepseek-ai/dsh` and `pi` / `@earendil-works/pi-coding-agent` CLIs and queries npm for their versions.
- DeepSeek Harness uses `DSH_HOME` or the default `~/.dsh/settings.yaml` and `.credentials.yaml` files.
- Pi means the `pi.dev` coding agent, not Inflection AI. The UI uses the official `pi.dev/logo-auto.svg` mark and follows `PI_CODING_AGENT_DIR` or `~/.pi/agent`.
- Pi Providers are projected to the official `models.json` and `settings.json` files while preserving unrelated providers, settings, headers, and model metadata. Empty keys do not erase managed credentials, and malformed files are left untouched.
- Pi installation and npm/pnpm upgrade paths retain `--ignore-scripts`; Pi requires Node.js `>=22.19.0`.
- Unsupported DeepSeek/Pi MCP switches and fake `mcp.json` files are gone. Skills synchronization remains supported.

## Verification

- `pnpm exec vitest run --maxWorkers=2 --minWorkers=1`: 117 files and 790 tests passed.
- DeepSeek/Pi focused regressions: 24 frontend tests plus Rust projection, lifecycle, and MCP-boundary tests passed.
- `pnpm typecheck`, `pnpm build:renderer`, `cargo fmt --check`, `cargo clippy`, `cargo test`, and `cargo check` passed.

## Windows release conditions

- `CC-Switch-v3.19.4-Windows-Setup.exe`: NSIS installer.
- `CC-Switch-v3.19.4-Windows.msi`: MSI installer.
- `CC-Switch-v3.19.4-Windows-Portable.zip`: portable package containing `cc-switch.exe`, `portable.ini`, and third-party notices.
- Installers are not Authenticode signed; Windows may show an unknown publisher prompt.
- No Tauri updater `.sig` or `latest.json` is generated, so in-app automatic updates are unavailable.
- Verify the downloaded files against `SHA256SUMS.txt` from this Release. A real install was not run on the development host to avoid replacing an existing CC Switch installation.
