# CCS Two Update v3.20.0

本版本是 CCS Two Update 的一次完整功能更新，重点补齐 **DeepSeek Harness 与 Pi Coding Agent 管理能力**，并完善 Codex 账号、代理路由、Provider 重试、配置迁移、备份恢复和 Windows 运行体验。

## 本次更新

### 新增功能

- **DeepSeek Harness 管理**
  - 增加 DeepSeek Harness 应用入口、独立配置读写和环境检测。
  - 支持 `DSH_HOME` 与默认配置目录。
  - 保留用户已有配置和密钥，检测到损坏配置时拒绝覆盖。
  - 同步 Provider、模型、Skills 和相关设置。

- **Pi Coding Agent 管理**
  - 增加 Pi 应用入口、独立图标和 Provider 管理。
  - 支持原生 `models.json` 的供应商增删改、启用、复制和节点同步。
  - 支持 Pi 的提示词、`SYSTEM.md`、`APPEND_SYSTEM.md`、斜杠命令模板和 Skills 管理。
  - 增加 Pi 会话浏览和 Session 用量统计。
  - Pi 的登录、默认供应商、默认模型和 `auth.json` 保持独立，CCS Two Update 不读取、不写入、不覆盖这些内容。
  - 首次启用时可导入已有 `models.json` 供应商，并增量同步会话用量。

- **Codex 多账号与账号绑定**
  - 认证中心支持保存多个 Codex OAuth 账号。
  - Codex 官方供应商可以直接绑定指定账号。
  - 切换供应商时写入完整令牌包，避免不同账号之间串用凭据。
  - 账号配额查询支持单卡配置、刷新和关闭。

- **审批与角色路由**
  - 增加 Codex 审批请求的原生、自动和回退三种模式。
  - 支持前端和后端 Agent Role 使用不同 Provider 与模型。
  - 角色路由带有配置拥有者校验、删除依赖保护和回退处理。

- **Provider 重试与迁移**
  - 支持 Provider 级限流、过载、服务端错误和网络错误重试。
  - 支持自定义错误匹配、有限重试和持续重试。
  - 当前 Provider 重试耗尽后继续进入原有故障转移流程。
  - 增加 Provider Transfer 预览、复制、冲突处理和执行结果反馈。

- **代理与模型能力**
  - 完善 Responses、Chat Completions 和 Anthropic Messages 转换。
  - 接通 Claude WebSearch 路由和 Codex Alpha Search。
  - 增加模型上下文窗口元数据和 1M 上下文开关。
  - 支持按模型配置 reasoning levels，并修正不同 Provider 的推理参数映射。
  - 所有主要模型下拉框支持按模型 ID 和 Provider 名称模糊搜索。

- **备份、同步与恢复**
  - 备份文件采用临时文件构建、完整校验后原子发布。
  - 恢复前先校验暂存数据库，避免损坏或截断文件替换当前数据。
  - 同步、恢复、导入导出和 Skills 文件状态统一串行处理。
  - 恢复数据库后重建相关应用配置、提示词和运行时设置。
  - 保留用户自定义模型目录和本地定价设置。

### 修复与改进

- 修复 DeepSeek Chat 路径缓存命中 token 统计为零、成本被高估的问题。
- 更新 DeepSeek V4 价格，并补充缺失的模型别名价格。
- 修复 WSL 配置目录无法更新或切换的问题。
- 改进 Windows CLI 检测：合并用户与系统 PATH，并识别独立安装目录。
- 修复 Windows 启动白屏/黑屏闪烁。
- 修复 MSI 模板写入错误注册表路径的问题。
- 修复 macOS 中文/日文输入法造成 Provider 字段重复、乱序或膨胀的问题。
- 修复跨年度用量趋势图的高亮点和提示框错位。
- 修复环境检查和冲突诊断可能长时间卡住的问题。
- 修复 Codex 接管恢复时覆盖新登录凭据的问题。
- 修复模型拉取错误回显 API Key 或自定义请求头的问题，短密钥也会脱敏。
- 改进 Grok Build、Claude Desktop、OpenCode、OpenClaw 等 Provider 表单的一致性。
- 改进应用生命周期锁、Windows 启动窗口、退出权限和代理状态恢复。
- 增加 WiX/MSI 与 NSIS 安装流程钩子及第三方组件声明。
