# CC Switch v3.19.4（フォーク版）

> `Jyy1529/ccs-two-update` の Windows 手動インストール版です。DeepSeek Harness と Pi Coding Agent を公式 CLI の契約に合わせ、Pi の製品名、アイコン、環境チェック、設定投影を修正しました。

**[English](v3.19.4-en.md) | [中文版](v3.19.4-zh.md)**

## 主な変更

- 設定画面で公式の `dsh` / `@deepseek-ai/dsh` と `pi` / `@earendil-works/pi-coding-agent` CLI を検出し、npm から最新版を確認します。
- DeepSeek Harness は `DSH_HOME`、または既定の `~/.dsh/settings.yaml` と `.credentials.yaml` を使用します。
- Pi は Inflection AI ではなく `pi.dev` coding agent を指します。公式の `pi.dev/logo-auto.svg` を表示し、`PI_CODING_AGENT_DIR` または `~/.pi/agent` を使用します。
- Pi Provider は公式の `models.json` と `settings.json` に投影され、既存の Provider、設定、ヘッダー、モデルメタデータを保持します。空のキーで既存の認証情報を消去せず、壊れたファイルも上書きしません。
- Pi の npm/pnpm インストールと更新では `--ignore-scripts` を維持します。Pi には Node.js `>=22.19.0` が必要です。
- DeepSeek/Pi の未対応 MCP スイッチと偽の `mcp.json` は廃止しました。Skills 同期は引き続き利用できます。

## 検証

- `pnpm exec vitest run --maxWorkers=2 --minWorkers=1`：117 ファイル、790 テスト合格。
- DeepSeek/Pi 回帰テスト：フロントエンド 24 テストと Rust の設定投影、ライフサイクル、MCP 境界テストに合格。
- `pnpm typecheck`、`pnpm build:renderer`、`cargo fmt --check`、`cargo clippy`、`cargo test`、`cargo check` に合格。

## Windows リリース条件

- `CC-Switch-v3.19.4-Windows-Setup.exe`：NSIS インストーラー。
- `CC-Switch-v3.19.4-Windows.msi`：MSI インストーラー。
- `CC-Switch-v3.19.4-Windows-Portable.zip`：`cc-switch.exe`、`portable.ini`、第三者 notices を含むポータブル版。
- インストーラーは Authenticode 署名されていないため、Windows で不明な発行元と表示される場合があります。
- Tauri updater の `.sig` と `latest.json` は生成しないため、アプリ内自動更新は利用できません。
- ダウンロード後は Release の `SHA256SUMS.txt` と照合してください。既存の CC Switch を置き換えないよう、開発ホストでは実際のインストールを実行していません。
