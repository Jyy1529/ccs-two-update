# CCS Two Update v3.20.1

本版整合上游 3.20.1，重点补齐供应商整理、Key 池、余额查询、应用管理隔离、配置保护和模型能力验证。

## 供应商文件夹与 Key 池

- 每个应用可以独立启用按 Base URL 自动分组。只有两个及以上供应商使用相同的归一化地址时才创建自动文件夹；单个地址保留未分组，手动归属不被自动整理覆盖。
- 支持手动创建、重命名、图标和颜色设置，以及文件夹拖动和菜单排序。
- 展开、收起文件夹不再提示“文件夹已更新”；实际修改仍有操作反馈。
- 文件夹可配置故障转移或轮询 Key 池，校验成员地址一致性，并提供成员启用、顺序、重试及冷却设置。
- 供应商保持独立卡片和配置，删除文件夹不会删除其中的供应商。

## 余额查询

- 支持内置余额接口识别和可复用自定义模板，展示逐 Key 查询结果。
- **未分组也可设置模板**：点击供应商余额按钮旁的设置图标，选择已有模板或新建模板。
- 模板优先级为“供应商独立模板 → 所属文件夹模板 → 内置识别”。单卡查询和文件夹批量查询使用同一规则。
- 查询使用所选供应商已保存的 Base URL 和 API Key；设置只写入 CC Switch 数据库，不修改客户端配置。
- 内置识别不支持当前服务商时，提示进入供应商余额设置，不再要求先创建文件夹。编辑共享模板会影响所有引用它的供应商和文件夹。
- 仅在额度独立、单位与币种一致且所有启用成员查询成功等条件满足时显示池总余额；避免重复 Key 或账号级余额被重复累计。

## 模型列表与能力验证

- 验证窗口新增“获取模型”和“刷新模型”，使用当前供应商的 Base URL 和显式 API Key 获取候选列表，支持搜索选择，也保留手动输入。
- 支持 OpenAI 兼容、Anthropic 和 Gemini 原生列表格式及相关分页；失败时不会自动换 Key、换供应商或启动能力测试。
- 基础验证覆盖鉴权、指定模型调用、流式响应、工具调用、结构化输出和合成图像输入。
- 高级诊断与实验性受控对比默认关闭，开始前展示目标、请求预算与可能产生费用的提示，并支持取消和本机历史记录。
- 验证固定具体供应商或 Key 池成员；不会切换生产 Provider、修改客户端配置或更新生产路由状态。
- 模型列表是服务商接口返回的数据，不保证所有列出的模型都可调用；能力验证结果也不认证模型真实身份。本版验证不支持订阅型 OAuth 渠道。

## 应用管理与配置保护

- 将“显示应用”与“由 CC Switch 管理”分开，为现有十种应用提供独立管理状态。
- 未托管应用保留数据库维护和只读能力验证入口，客户端写入与代理接管受到后端权限检查。
- 增加配置变更预览、字段保护、版本检查和冲突处理，避免以旧配置静默覆盖用户修改。
- 修复 Codex 保存流程重复加锁导致卡住的问题，并补充简体中文、繁体中文、英文和日文文案。

## Windows 下载与安装

- `CC-Switch-3.20.1-Windows-Setup.exe`：常规安装版。
- `CC-Switch-3.20.1-Windows.msi`：MSI 安装版。
- `CC-Switch-3.20.1-Windows-Portable.zip`：便携版，解压后运行。
- `SHA256SUMS.txt`：三个下载文件的 SHA256 校验值。

升级前请备份配置和数据库，并在自行安装时退出旧版及托盘进程。此版本包含数据库迁移；需要降级时应恢复对应备份，不要直接使用旧版打开迁移后的数据库。

此批安装包未进行 Windows 代码签名，也不包含自动更新签名或 `latest.json`，请手动下载更新。没有替换更新公钥或绕过签名校验。

## 验证边界

使用项目 TypeScript、Vitest 和相关 Rust 单元/集成测试进行验证，网络行为使用本地模拟服务与假凭据。构建检查包含前端资源实际嵌入、安装包元数据和交付文件校验。

没有使用真实 API Key 实测，也没有执行安装器或启动用户的 CC Switch；这些离线与自动化验证不等同于实机启动验收。修正的前端资源相对路径已纳入本地打包检查，避免把本地目录地址误当作应用入口。
