# CC Switch v3.19.3（フォーク版）

> `Jyy1529/ccs-two-update` の Windows 手動インストール版です。Provider の機能スコープ制御と DeepSeek / Pi の MCP・Skills 永続化を仕上げました。

**[English →](v3.19.3-en.md) | [中文版 →](v3.19.3-zh.md)**

## 主な変更

- ローカルプロキシの自動リトライ、Codex の Agent Role ルーティング、Codex の承認モデルルーティングを個別に有効化し、対象アプリを制限できる Provider 機能スコープを追加しました。
- DeepSeek / Pi の MCP・Skills 有効状態を schema v17 に保存します。MCP エントリは各アプリ固有の `mcp.json` に同期し、Skills 状態はデータベースに独立して保持します。
- DeepSeek / Pi の設定ディレクトリ選択、既定値へのリセット、多言語文言、MCP チェックボックス、Skills インポート状態を追加しました。
- DeepSeek / Pi の Provider フォームは Claude の `env/config` や未対応の Universal Provider を使わず、`baseUrl` / `apiKey` / `model` のフラット JSON を保存します。
- Codex Agent Role のリスニングアドレス検証を厳密な loopback IP にし、wildcard・外部アドレス・不正な文字列を拒否します。

## 検証

- `pnpm typecheck`、`pnpm format:check`：合格。
- DeepSeek/Pi フォーム、MCP、ディレクトリ、機能スコープのフロントエンド回帰テスト：合格。
- `cargo fmt --check`、`cargo clippy --all-targets --all-features -- -D warnings`：合格。
- Rust library と指定した統合テスト：合格（詳細は `docs/handoff-gpt55-report.md`）。

## Windows リリース条件

- Windows `x86_64` 向け MSI と NSIS は手動ダウンロード専用の成果物です。
- インストーラーは Authenticode 署名されていないため、Windows で不明な発行元と表示される場合があります。
- Tauri updater artifact、`.sig`、`latest.json` は生成していません。アプリ内自動更新は利用できず、上流の更新チャンネルも参照しません。
- GitHub Release に記載した SHA-256 を確認してください。開発ホストには既存の CC Switch がインストールされているため、実際のインストール/アップグレードは実行していません。Windows Sandbox または VM で確認してください。
