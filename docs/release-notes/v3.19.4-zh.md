# CC Switch v3.19.4（二次开发版）

> `Jyy1529/ccs-two-update` 的 Windows 手动发布版。本版对 DeepSeek Harness 和 Pi Coding Agent 做了官方契约校正，并修复 Pi 图标、环境检查和配置投影问题。

**[English](v3.19.4-en.md) | [日本語](v3.19.4-ja.md)**

## 主要更新

- 设置页环境检查现在识别官方 `dsh` / `@deepseek-ai/dsh` 与 `pi` / `@earendil-works/pi-coding-agent`，并从 npm 查询版本。
- DeepSeek Harness 使用 `DSH_HOME` 或默认的 `~/.dsh/settings.yaml` 与 `.credentials.yaml`。
- Pi 指 `pi.dev` coding agent，不是 Inflection AI；使用官方 `pi.dev/logo-auto.svg` 图标，配置目录遵循 `PI_CODING_AGENT_DIR` 或 `~/.pi/agent`。
- Pi Provider 投影到官方 `models.json` 与 `settings.json`，保留其他 Provider、设置、请求头和模型元数据；空密钥不会清除已有受管密钥，损坏文件不会被覆盖。
- Pi 的 npm/pnpm 安装和升级路径保留 `--ignore-scripts`；Pi 要求 Node.js `>=22.19.0`。
- DeepSeek/Pi 不再显示不受官方支持的 MCP 开关，也不创建伪 `mcp.json`；Skills 同步仍可用。

## 功能审核

本版已通过：

- `pnpm exec vitest run --maxWorkers=2 --minWorkers=1`：117 个测试文件、790 个测试通过。
- DeepSeek/Pi 聚焦回归：前端 24 个测试通过；Rust 官方配置、生命周期元数据和 MCP 边界测试通过。
- `pnpm typecheck`、`pnpm build:renderer`、`cargo fmt --check`、`cargo clippy`、`cargo test`、`cargo check`。

## Windows 发布条件

- `CC-Switch-v3.19.4-Windows-Setup.exe`：NSIS 安装版。
- `CC-Switch-v3.19.4-Windows.msi`：MSI 安装版。
- `CC-Switch-v3.19.4-Windows-Portable.zip`：便携版，包含 `cc-switch.exe`、`portable.ini` 和第三方声明。
- 安装器未进行 Authenticode 签名，Windows 可能显示未知发布者。
- 本版不生成 Tauri updater `.sig` 或 `latest.json`，应用内自动更新暂不可用。
- 下载后请使用同一 Release 中的 `SHA256SUMS.txt` 校验资产；开发主机未执行真实安装以避免覆盖现有 CC Switch。
