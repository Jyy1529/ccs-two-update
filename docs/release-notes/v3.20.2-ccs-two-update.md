# CCS Two Update v3.20.2

本版在完整的 3.20.1 基线上增加供应商 API 请求调试，保留供应商分组、Key 池、余额查询、应用管理隔离、配置保护和模型能力验证。

## API 请求调试

- 在 API Key 供应商卡片点击终端方框图标，自动读取该供应商的地址、Key 和已配置模型。
- Codex 优先使用当前供应商表中的 Key，避免旧 `auth` 字段覆盖已更新的供应商凭据。
- 支持 Chat Completions、Responses、Anthropic Messages 和 Gemini GenerateContent；模型可以下拉选择、刷新或手动输入。
- 默认提示词为“搜索一下今日科技和ai热点”，流式默认开启。提示词是否触发联网搜索取决于供应商能力。
- 可复制 Bash / zsh 或 PowerShell 7.3+ cURL。预览默认遮盖 Key，复制的可执行命令包含真实 Key。
- 展示完整请求快照、HTTP 状态、重复响应头和原始 JSON/SSE，包括事件、usage 和 `[DONE]`。
- 支持取消；超时、中断、非 UTF-8 响应和 32 MiB 响应上限均明确标记结果不完整，保留已经接收的内容。
- Gemini 原生模型刷新支持分页、网关前缀、去重与生成能力过滤；切换测试接口不改变模型发现所用的供应商协议。

请求调试只在用户操作时发送请求，不自动重试、跟随重定向、参与故障转移或写入客户端配置。原生 OAuth、云签名和 OMO 配置不使用此入口。详细说明见 [API 请求调试与配置保护诊断](../api-request-debugger-zh.md)。

## Windows 交付

- `CC-Switch-3.20.2-Windows-Setup.exe`：NSIS 安装版。
- `CC-Switch-3.20.2-Windows.msi`：MSI 安装版。
- `CC-Switch-3.20.2-Windows-Portable.zip`：便携版，包含程序、`portable.ini` 和第三方声明。
- `SHA256SUMS.txt`：三个交付文件的 SHA-256 校验值。

本地打包沿用已有的未签名 Windows 构建流程，不生成自动更新签名或 `latest.json`，不改变更新公钥。构建安装包不会自动替换正在运行的程序；手动升级前应退出旧版和托盘进程。
